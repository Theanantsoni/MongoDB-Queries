# MongoDB-Queries

 MongoDB Query Practice Notes

-This repository contains my MongoDB query practice notes, created while learning and practicing MongoDB from YouTube playlists and various online resources.

-The goal of this repository is to build strong fundamentals and intermediate-level understanding of MongoDB by practicing real commands and queries used in projects and interviews.

-All examples are written in a console-friendly format and focus on practical usage rather than theory.

 📚 Learning Source

- Practiced MongoDB queries from YouTube playlists
- Referred online documentation and tutorials
- Focused on hands-on query execution and experimentation
- Learned by testing queries directly in MongoDB shell
